第一題

1. 匯入模組

import math
math 是 Python 的數學模組，用來執行數學相關的計算。


2. 定義半徑和圓心

r = 5

cx, cy = 4.5, 4.5

r是圓的半徑

cx, cy 是圓心的座標


3. for迴圈：產生區域

for y in range(10):
    for x in range(10):
產生一個範圍為10x10 的區域


4. 計算與圓心的距離

distance = math.sqrt((x - cx) ** 2 + (y - cy) ** 2)
每個點 (x, y) 到圓心 (cx, cy) 的距離使用公式計算：距離=(x−cx
)2+(y−cy)2

將這個點的座標代入後，距離會決定該點是否屬於圓內。


5. 判斷並繪製圖案

if distance <= r:
            print(' * ', end='')
        else:
            print('   ', end='')
如果距離 distance 小於或等於圓的半徑 r，表示該點在圓內，則打印 " * "。

否則打印空白 " "，代表圓外的區域。

end="" 可以確保在打印完每一個*之後不會換行，因為預設的end="/n" 會讓打印完之後自動換行。


6. 換行

 print()
完成一行後，透過這行程式碼換行，準備打印下一行。
第二題
1. 匯入模組
from browser import html
from browser import document as doc
import math

html 模組，用來建立和操作 HTML 元素。
document 物件，用來操作 DOM（Document Object Model），將 <canvas> 添加到網頁。
math模組，提供數學函式，這裡用於計算格子中心與圓心的距離。

2.建立 <canvas> 物件

canvas = html.CANVAS(width=400, height=400)
brython_div = doc["brython_div1"]
brython_div <= canvas

建立一個 <canvas> 元素，設定寬和高為 400 像素，作為繪圖的畫布。

在 HTML 文件中尋找 brython_div1 的元素，並將畫布插入到 brython_div1

3.設定格子像素大小

gs = 20

定義每個格子的邊長為 20 像素

4.取得繪圖上下文

ctx = canvas.getContext("2d")

取得 <canvas> 的 2D 繪圖上下文，之後使用它來繪製格子、填充顏色等操作。

5.繪製單個矩形

def dRect(lux, luy, w, h, s=1, c='#ff0000'):
    ctx.lineWidth = s
    ctx.strokeStyle = c
    ctx.beginPath()
    ctx.rect(lux, luy, w, h)
    ctx.stroke()

定義函式 dRect，用於繪製矩形的邊框。
參數：
lux, luy: 矩形左上角的座標。
w, h: 矩形的寬和高。
s: 線條的寬度
c: 線條顏色
設定矩形邊框的線條寬度。
設定矩形邊框的顏色。
開始繪製新的路徑，確保不會與前面的路徑混淆。
在 (lux, luy) 座標位置繪製一個寬 w、高 h 的矩形。
繪製矩形的邊框。

6.繪製整個格子網格

def grid(width, height, grid_pix):
    for i in range(width):
        for j in range(height):
            dRect(i * grid_pix, j * grid_pix, grid_pix, grid_pix, 1, "lightgrey")

定義函式 grid，用於繪製多個矩形構成的網格。
參數：
width, height: 網格的行數和列數。
grid_pix: 每個格子的邊長（像素大小）。
計算每個格子的座標，並繪製淺灰色的矩形作為網格。

7.填充顏色

def fill(x, y, color):
    ctx.fillStyle = color
    ctx.fillRect(x, y, gs, gs)

定義函式 fill，用於填充指定位置的格子。
參數：
x, y: 填充的矩形左上角座標。
color: 填充顏色。
設定填充的顏色。
在 (x, y) 座標繪製寬高為 gs 的矩形，填充顏色。

8.繪製圓形內部

def draw_circle(grid_size, circle_radius, grid_pix, center):
    cx, cy = center
    for i in range(grid_size):
        for j in range(grid_size):
            grid_center_x = i + 0.5
            grid_center_y = j + 0.5
            distance = math.sqrt((grid_center_x - cx)**2 + (grid_center_y - cy)**2)
            if distance <= circle_radius:
                fill(i * grid_pix + 1, j * grid_pix + 1, "black")

定義函式 draw_circle，用於計算圓形的格子範圍並填色。
參數：
grid_size: 格子網的邊長。
circle_radius: 圓的半徑（單位為格子數）。
grid_pix: 每格的邊長像素。
center: 圓心座標（以格子數計算）。

計算每個格子的中心座標。
使用距離公式，計算格子中心與圓心的距離。
判斷該格子是否位於圓形內部或邊界。
若條件成立，將該格子填充黑色。

9.執行主程式

grid(10, 10, gs)
draw_circle(10, 5, gs, (5, 5))

繪製 10×10 的網格，每格邊長為 20 像素。
繪製一個圓心在網格 (5, 5)、半徑為 5 格的實心圓形。
